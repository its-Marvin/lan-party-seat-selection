Event

An event goes live automatically when its registration opens and is archived when it ends. Only one event can be open at a time, so registration can only open after the previous event has ended.

⚠️ No event code is set, so registration is closed and visitors can't see any names. Set a code under Settings → Access to open registration.

Seat layout

Drag groups and area elements to arrange them on the event area (or select one and use the arrow keys). One grid square is one seat; every table seats two people. Seats are numbered per group: A1, A2, … Area elements can be resized with the handle in their corner (or Shift + arrow keys).
